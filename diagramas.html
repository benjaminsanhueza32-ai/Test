Vista de Desarrollo

Organiza el código en subsistemas: el cliente web estático (las 3 páginas, estilos y módulo JavaScript), la API REST con sus servicios y la capa de datos. Vista de Procesos

Describe la dinámica de los procesos clave. El checkout verifica el stock antes de confirmar; si dos clientes compran la última unidad a la vez, la verificación y el descuento se ejecutan en una misma transacción y el segundo recibe un error 409. El filtrado se ejecuta solo en el cliente, sin bloquear la carga inicial.

Vista Física (Despliegue)

Muestra la topología de ejecución. Los archivos estáticos se sirven desde un hosting con CDN (RNF01, carga inicial menor a 2 s). Todo el tráfico va por HTTPS y las funciones de administración exigen un token JWT (RNF02).
