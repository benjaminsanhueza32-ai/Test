# Sockbuster Video & Socks

Prototipo web de la tienda de calcetines temáticos Sockbuster. Evaluación Sumativa 03, Modelamiento de soluciones informáticas (TI3025).

**Autor:** Benjamín Samhueza

**Sitio publicado:** <PEGAR AQUÍ EL ENLACE DE GITHUB PAGES>

## Páginas
- `index.html`: presentación de la marca
- `catalogo.html`: catálogo interactivo con filtros, detalles, carrito y checkout simulado
- `diagramas.html`: arquitectura UML en vistas 4+1 (Mermaid)
